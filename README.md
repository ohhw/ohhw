## Commit Message 가이드라인

`타입(스코프): 제목` 형식으로 작성합니다. 스코프는 필요한 경우에만 붙입니다.

| 타입 | 사용 시점 | 예시 |
| --- | --- | --- |
| `feat` | 기능 추가·개선 | `feat(ui): 다크 모드 추가` |
| `fix` | 버그 수정 | `fix(search): 검색 결과 누락 수정` |
| `docs` | 문서 변경 | `docs(readme): 설치 방법 보완` |
| `style` | 동작에 영향 없는 표현·포맷 변경 | `style(button): 버튼 간격 정리` |
| `refactor` | 기능 변경 없는 코드 구조 개선 | `refactor(api): 응답 처리 함수 분리` |
| `chore` | 설정·빌드·의존성 관리 | `chore(deps): 의존성 버전 갱신` |

제목은 50자 이내, 마침표 없이 작성합니다. 영문 제목은 명령조를 쓰고, 커밋 하나에는 목적 하나만 담습니다. 설명이 더 필요하면 제목 다음에 한 줄을 비우고 `-` 목록으로 적습니다.
